3 Learning Loops

Loop 1: Real-Time

Every interaction
  • Email sent → training_data row
  • Reply received → classify intent
  • Outcome recorded (positive/negative)
  • Causal attribution: which sentence?
  • Pending outcomes: 7/14/30-day re-check
  • 14-day silence → attribute_silence()
  • prospect_state updated per lead
  • MAGMA: temporal + entity edges

Loop 2: Daily Reflection

Every night
  • Gather 24h metrics + outcomes
  • Claude analyzes: 3-5 insights
  • Contradiction detection vs existing
  • Store → Postgres + Mem0 + MAGMA
  • If 15%+ metric gain → extract rule
  • memory_gc(): prune + dedup + flag
  • Confidence decay on stale rules
  • MAGMA causal consolidation (async)

Loop 3: Sleep Cycle + LoRA

Nightly debate · Weekly training
  • Alpha (Opus): propose 3-5 changes
  • + MAGMA causal chains as context
  • Beta (Opus): debate with git history
  • Survive → backprop to soul + config
  • Evaluate rules: deactivate regressions
  • A/B test analysis: n≥30 gate
  • If 500+ examples → OPLoRA training
  • 30-day window, recency-boosted
  • Deploy to Ollama → better emails
