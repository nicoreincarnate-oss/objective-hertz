### 2. Claude Code 2.1.89 + Sonnet 4.6 — Headless Hook Improvements (Released Today)
- **What**: Claude Code 2.1.89 released April 1, 2026. Key features:
  - **`defer` permission in `PreToolUse` hooks** — headless sessions can pause at a tool call and resume with `-p --resume` for hook re-evaluation. Eliminates hard blocking in automated pipelines.
  - **`PermissionDenied` hook** — fires after auto-mode classifier denials; return `{retry: true}` to allow model retry. Enables graceful fallback logic.
  - **`MCP_CONNECTION_NONBLOCKING=true`** — for `-p` mode, skips MCP connection wait entirely; MCP server connections bounded at 5s.
  - **Named subagents** in @ mention typeahead.
  - `CLAUDE_CODE_NO_FLICKER=1` for flicker-free alt-screen rendering in headless/server environments.
  - **Claude Sonnet 4.6** launched as the latest balanced model — improved agentic search performance, reduced token consumption.
  - **Web search + WebFetch tools now GA** with dynamic result filtering (code execution filters before context window — reduces token costs).
- **Sources**: [Claude Code Changelog](https://code.claude.com/docs/en/changelog) · [Claude Platform Release Notes](https://platform.claude.com/docs/en/release-notes/overview) · [GitHub Releases](https://github.com/anthropics/claude-code/releases)
- **Relevance**: **perseus/daemon.py + openjarvis/ + shared/llm_client.py** — The `defer` + `PermissionDenied` hook pattern is directly useful for Perseus's scheduled task runner. Currently, headless sessions that hit a tool permission boundary fail hard. With 2.1.89, they can pause, surface the issue, and resume — critical for 24/7 unattended operation. MCP_CONNECTION_NONBLOCKING also matters for Perseus: if a daemon starts with a slow MCP server, the 5s cap prevents startup hangs. The new Sonnet 4.6 model string should replace any hardcoded `claude-sonnet-4-5` references.
- **Action**:
  1. Update Claude Code to 2.1.89 (`npm install -g @anthropic-ai/claude-code`)
  2. Add `PermissionDenied` hook in `.claude/hooks/` to handle classifier denials gracefully — log + retry for pipeline-safe tools
  3. Set `MCP_CONNECTION_NONBLOCKING=true` in Perseus daemon environment to prevent startup hangs
  4. Audit `llm_client.py` for `claude-sonnet-4-5` references — update to `claude-sonnet-4-6`
