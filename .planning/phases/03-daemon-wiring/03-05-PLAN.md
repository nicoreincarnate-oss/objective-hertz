### Task 1: Wire Draw Things branch into `clawdbot/asset_generator.py`

- Read current `asset_generator.py` to find the image-gen dispatch logic
- Add an opt-in branch at the top of the image-gen function:
  ```python
  if os.environ.get("ENABLE_DRAW_THINGS", "false").lower() == "true":
      try:
          from shared.imagegen.draw_things_client import DrawThingsClient
          dt = DrawThingsClient()
          if await dt.is_available():  # 127.0.0.1:7860 reachable
              result = await dt.generate(prompt=prompt, style=style, size=size)
              if result.success:
                  return result.image_bytes
              # Fall through to Recraft on Draw Things failure
      except ImportError:
          # Draw Things client not installed — dead path, expected
          pass
      except Exception as exc:
          logger.warning("Draw Things branch failed, falling through to Recraft: %s", exc)
  # Existing Recraft path (unchanged)
  ...
  ```

- Add a logger call noting which path was taken for observability
