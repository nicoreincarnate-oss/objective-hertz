## Tasks

### Task 1: Apply migration to the 8 daemons + orchestrator

Run `migrate_to_litellm.py --apply` and commit each daemon atomically.

**Command sequence** (from worktree root):

```bash
# Dry run first, capture the JSON report for deferred multi-line calls
/opt/homebrew/bin/python3 -m scripts.migrate_to_litellm --dry-run --report /tmp/migrate_dryrun.json

# Apply per-daemon via --path flag (atomic commits per daemon)
for daemon in perseus titan hermes clawdbot ruflo deerflow_research openjarvis conway; do
  /opt/homebrew/bin/python3 -m scripts.migrate_to_litellm --apply --path "$daemon/"
  git add "$daemon/"
  git commit -m "refactor($daemon): migrate llm.generate() sites to include daemon_name + operation metadata"
done

# Then orchestrator.py
/opt/homebrew/bin/python3 -m scripts.migrate_to_litellm --apply --path orchestrator.py
git add orchestrator.py
git commit -m "refactor(orchestrator): migrate llm.generate() sites to include daemon_name + operation metadata"
```

**Verification per commit:**
- `/opt/homebrew/bin/python3 -c "import ast; ast.parse(open('<daemon>/<file>').read())"` for each modified file
- `grep -n 'operation=\|daemon_name=' <daemon>/*.py` — confirm kwargs added

**If multi-line calls deferred:** review `/tmp/migrate_to_litellm_manual_review.json` and hand-migrate using libcst or by inserting kwargs into the call's closing paren line. Commit separately with `refactor(<daemon>): hand-migrate N multi-line llm.generate() sites`.
