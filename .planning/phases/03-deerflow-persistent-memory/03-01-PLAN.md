# Plan 03-01: Memory Store + Cache + Migration

## Objective

Build the complete DeerFlow persistent memory system as a standalone module.

Read `.planning/phases/3/PLAN.md` Tasks 1-5, 7 for full details.

## Tasks

### Task 1: Migration 019 — daemon_memory table (MEM-01)

**File:** `scripts/migrations/019-daemon-memory.sql`

Create table with: daemon_name, memory_type (episodic/semantic), key, content JSONB, importance, access_count, expires_at (NULL for semantic), timestamps. UNIQUE constraint on (daemon_name, memory_type, key). Three indexes. Plus daemon_memory_stats VIEW.

See `.planning/phases/3/PLAN.md` Task 1 for exact SQL.

**Commit:** `feat(03-01): add migration 019 — daemon_memory table + stats view`

### Task 2: Working memory (MEM-02)

**File:** `shared/daemon_memory.py` (new)

Create `WorkingMemory` class — in-process dict with max_items and LRU-like eviction. NOT in Postgres, lost on restart by design.

**Commit:** `feat(03-01): add WorkingMemory in-process store`

### Task 3: DaemonMemoryStore — episodic + semantic (MEM-03, MEM-04)

**File:** `shared/daemon_memory.py` (extend)

Create `DaemonMemoryStore` implementing `MemoryStore` Protocol:
- `save_episodic()` with 30-day TTL, UPSERT
- `cleanup_expired()` for daily job
- `save_semantic()` — permanent, triggers compression at 10K row cap
- `_compress_memories()` — merge bottom 20% by importance (use MAGMA if available, else simple merge)
- `load()` — load memories by daemon and type
- `save()` — save memory entry
- `cleanup()` — cleanup expired + return count

Must pass `isinstance(DaemonMemoryStore(), MemoryStore)`.

**Commit:** `feat(03-01): add DaemonMemoryStore with episodic/semantic tiers`

### Task 4: JSON cache for fast startup (MEM-05)

**File:** `shared/daemon_memory.py` (extend)

Create `MemoryCache`:
- `load_cache(daemon_name)` — read from `~/.objective-hertz/memory-cache/{daemon}.json`
- `save_cache(daemon_name, memories)` — write JSON
- `save_with_cache(daemon_name, key, content)` — write-through to Postgres + cache
- Startup < 500ms target

**Commit:** `feat(03-01): add JSON write-through memory cache`

### Task 5: Per-daemon memory isolation (MEM-07)

**File:** `shared/daemon_memory.py` (extend)

Enforce isolation using DNA profile `memory_domains` field:
- Each daemon can only access its own memory domains
- Cross-daemon access raises PermissionError
- Read DNA profiles from `soul/dna/{daemon}.yaml`

**Commit:** `feat(03-01): add per-daemon memory isolation via DNA profiles`
