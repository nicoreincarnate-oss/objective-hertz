# Plan 03-02: Daemon Integration + Scheduler + Tests

## Objective

Wire memory system into daemon lifecycle and add tests.

Read `.planning/phases/3/PLAN.md` Tasks 6, 8 for full details.

## Tasks

### Task 1: Memory injection into AgentBase (MEM-06)

**File:** `shared/agent_base.py`

Add to AgentBase:
- `_memory: DaemonMemoryStore | None` attribute
- `_working_memory: WorkingMemory` attribute
- `_load_memory()` — called during `register()`, loads from cache then background Postgres sync
- `_save_memory()` — called during `deregister()`, persists working memory to episodic
- Gate all operations behind `ENABLE_DEERFLOW_MEMORY` feature flag

**Commit:** `feat(03-02): inject memory lifecycle into AgentBase register/deregister`

### Task 2: Perseus daily cleanup job

**File:** `perseus/scheduler.py`

Add scheduled task for daily memory cleanup:
- Call `DaemonMemoryStore().cleanup_expired()` once per day
- Log count of expired entries deleted
- Add to existing scheduler task list

**Commit:** `feat(03-02): add daily memory cleanup to Perseus scheduler`

### Task 3: Test suite (MEM-08)

**Files:** `tests/shared/test_daemon_memory.py`, `tests/shared/test_memory_cache.py`

Tests:
- Working memory: set/get/eviction at max_items
- Episodic: save/load/expire cycle (mock DB)
- Semantic: save, compression trigger at cap (mock DB)
- JSON cache: round-trip, startup time
- Memory isolation: cross-daemon access raises PermissionError
- `isinstance(DaemonMemoryStore(), MemoryStore)` Protocol check
- AgentBase: _load_memory called during register, _save_memory during deregister
- Feature flag off = no memory operations
- daemon_memory_stats view (mock query)

Run: `PYTHONPATH=. pytest tests/shared/test_daemon_memory.py tests/shared/test_memory_cache.py -v`

**Commit:** `test(03-02): add DeerFlow memory test suite`
