# Plan 06-01: PQC Core + SecureConfig + Migration

## Objective

Build the complete PQC crypto layer. ARM64 spike validates feasibility first.

Read `.planning/phases/6/PLAN.md` Tasks 1-6 for full details.

## Important Implementation Note

The ARM64 validation spike (Task 1) is a decision gate. Since we're building for tests
and the PQC libraries may not be installable:
- Build all PQC code with graceful fallback: try liboqs-python, then pqcrypto, then
  pure-Python simulation for testing
- The HybridEncryptor and QuantumSafeSigner should have a fallback mode using only
  the `cryptography` library (AES-256-GCM + Ed25519) when PQC libs unavailable
- This lets us test the integration fully even if PQC libs aren't installed

## Tasks

### Task 1: ARM64 validation spike (PQC-01)

**File:** `scripts/pqc-validation-spike.py`

Try installing and testing PQC libraries. Record results in a comment/docstring.
If PQC libs unavailable, document fallback to `cryptography` library.

**Commit:** `feat(06-01): add PQC ARM64 validation spike script`

### Task 2: HybridEncryptor (PQC-02)

**File:** `conway/pqc.py` (new)

Hybrid ML-KEM-768 + AES-256-GCM:
- encrypt(plaintext) → ciphertext
- decrypt(ciphertext, private_key) → plaintext
- Fallback: AES-256-GCM only when PQC libs unavailable
- Implements CryptoProvider Protocol

**Commit:** `feat(06-01): add HybridEncryptor — ML-KEM-768 + AES-256 hybrid encryption`

### Task 3: QuantumSafeSigner (PQC-03)

**File:** `conway/pqc.py` (extend)

ML-DSA-65 signatures:
- sign(message) → signature
- verify(message, signature, public_key) → bool
- Fallback: Ed25519 when PQC libs unavailable

**Commit:** `feat(06-01): add QuantumSafeSigner — ML-DSA-65 transaction signatures`

### Task 4: SecureConfig (PQC-04)

**File:** `shared/secure_config.py` (new)

Encrypt .env secrets at rest:
- encrypt_env() — reads .env, encrypts each value, writes .env.encrypted
- get(key) → decrypted value
- Fallback to os.environ when encrypted file unavailable

**Commit:** `feat(06-01): add SecureConfig for .env encryption at rest`

### Task 5: Migration 022 + per-agent key derivation (PQC-05, PQC-06)

**Files:** `scripts/migrations/022-pqc-keys.sql`, `conway/pqc.py` (extend)

encrypted_keys table with dual-key support. Per-agent HKDF key derivation.

**Commit:** `feat(06-01): add migration 022 + per-agent HKDF key derivation`

### Task 6: Key rotation (PQC-07)

**File:** `conway/pqc.py` (extend)

rotate_keys(agent_name) — new PQ keypair, re-encrypt, 30-day dual-key overlap.

**Commit:** `feat(06-01): add PQC key rotation with 30-day dual-key period`
