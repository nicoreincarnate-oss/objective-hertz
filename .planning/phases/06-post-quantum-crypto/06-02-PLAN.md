# Plan 06-02: Feature Flag + Tests

## Objective

Wire PQC into Conway wallet and write comprehensive tests.

Read `.planning/phases/6/PLAN.md` Task 8 for details.

## Tasks

### Task 1: Feature flag + wallet integration (PQC-08)

**File:** `conway/wallet.py`

- PQC_ENABLED=false → classical encryption (existing)
- PQC_ENABLED=true → hybrid PQC encryption via HybridEncryptor
- Wire QuantumSafeSigner into send_usdc() for transaction signing
- Graceful: if PQC import fails, fall back to classical with warning

**Commit:** `feat(06-02): wire PQC into Conway wallet with feature flag`

### Task 2: Comprehensive test suite

**Files:** `tests/conway/test_pqc.py`, `tests/shared/test_secure_config.py`

Tests:
- HybridEncryptor: encrypt/decrypt round-trip (both PQC and fallback modes)
- QuantumSafeSigner: sign/verify, invalid signature rejected
- CryptoProvider Protocol compliance
- Dual-key period: both classical and PQC keys work
- Per-agent key derivation: agent A can't decrypt agent B's keys
- Key rotation: new keys work, old keys valid during transition
- SecureConfig: encrypt .env, read back, handle missing file
- Feature flag: PQC_ENABLED on/off behavior
- Graceful fallback: PQC libs unavailable → classical works

Run: `PYTHONPATH=. pytest tests/conway/test_pqc.py tests/shared/test_secure_config.py -v`

**Commit:** `test(06-02): add PQC + SecureConfig test suite`

## Acceptance Criteria

- [ ] Feature flag toggles cleanly
- [ ] Conway wallet uses PQC when enabled
- [ ] All tests pass
