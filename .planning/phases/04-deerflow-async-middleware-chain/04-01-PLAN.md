# Plan 04-01: Middleware Chain + All Middlewares + Migration

## Objective

Build the complete middleware system as a standalone module.

Read `.planning/phases/4/PLAN.md` Tasks 1-7 for full implementation details.

## Tasks

### Task 1: MiddlewareChain core (MW-01)

**File:** `shared/middleware.py` (new)

Create `MiddlewareChain` class with:
- `use(middleware)` — add to chain, returns self for chaining
- `execute(ctx, handler)` — compose pattern: each middleware wraps next
- Async throughout: `async def middleware(ctx, next_fn) -> StageResult`

**Commit:** `feat(04-01): add MiddlewareChain with async compose pattern`

### Task 2: Per-pipeline middleware config (MW-02, MW-08)

**File:** `shared/middleware.py` (extend)

- `PIPELINE_CONFIGS` dict: titan=[budget,dna,anti_slop,memory,telemetry], clawdbot, hermes, perseus
- `build_chain(pipeline_name)` — constructs chain from config
- `MIDDLEWARE_REGISTRY` dict mapping names to functions
- Env override: `TITAN_MIDDLEWARE_ORDER=budget,dna,telemetry`
- Validation: warn if ordering has anti-slop before DNA

**Commit:** `feat(04-01): add per-pipeline middleware config with env override`

### Task 3: MemoryMiddleware (MW-03)

Pre-stage: inject relevant memories into ctx. Post-stage: save outcome as episodic memory. Feature-flag gated.

**Commit:** `feat(04-01): add MemoryMiddleware — inject/save memories around stages`

### Task 4: DNAGuardMiddleware (MW-04)

Check tool permissions against DNA boundaries. Block unauthorized tools with logged warning.

**Commit:** `feat(04-01): add DNAGuardMiddleware — boundary enforcement`

### Task 5: AntiSlopMiddleware (MW-05)

Score content-producing stages (email_compose, site_build, alert_compose). Run secret detection. Pass non-content stages through.

**Commit:** `feat(04-01): add AntiSlopMiddleware — quality scoring + secret blocking`

### Task 6: TelemetryMiddleware + migration 020 (MW-06, MW-07)

**Files:** `shared/middleware.py` (extend), `scripts/migrations/020-stage-metrics.sql` (new)

Create `stage_metrics` table. TelemetryMiddleware records timing, success to DB (fire-and-forget).

**Commit:** `feat(04-01): add TelemetryMiddleware + migration 020 stage_metrics table`

### Task 7: BudgetCheckMiddleware

Check budget before stage execution. Reject if over $800/mo cap. Uses shared/observability.py get_metrics_summary.

**Commit:** `feat(04-01): add BudgetCheckMiddleware — $800/mo cap enforcement`
