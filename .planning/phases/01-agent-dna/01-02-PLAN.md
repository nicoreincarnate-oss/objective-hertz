# Plan 01-02: DNA Injection + Daemon Integration + Tests

## Objective

## Tasks

### Task 1: Inject DNA into generate() + daemon integration (DNA-05)

**Files:** `shared/llm_client.py`, all 5 daemon.py files

#### 1a. Add parameters to generate()
In `shared/llm_client.py generate()`:
- Add `use_dna: bool = False` and `daemon_name: str = ""` parameters
- When `use_dna=True` AND `ENABLE_DNA_PROFILES` env var is truthy:
  - Load DNA via `AgentDNA(daemon_name).get_dna(daemon_name)`
  - Check circuit breaker before injecting
  - Prepend to system parameter: `f"{dna_text}\n\n---\n\n{system}"`
- When flag is off or use_dna=False: zero change to behavior

#### 1b. Update daemon calls
For each daemon's main reasoning/generation LLM calls:
- Add `use_dna=True, daemon_name="titan"` (etc.)
- Only main reasoning calls — NOT simple formatting/parsing calls
- Search each daemon.py for `generate(` or `llm.generate(` calls

**Commit:** `feat(01-02): inject DNA into LLM generate() + update all 5 daemons`
