# Plan 01-01: DNA Documents + Loader + Circuit Breaker

## Objective

Create the DNA layer — universal principles document, per-daemon profiles, loader with Protocol compliance, and circuit breaker.

Read `.planning/phases/1/PLAN.md` Tasks 1-4 for full implementation details.

## Tasks

### Task 1: Universal engineering DNA (DNA-01)

**File:** `soul/engineering_dna.md` (new)

Create markdown document with 7 principle categories:
1. Security — Never expose credentials, validate inputs, least privilege
2. Compliance — CAN-SPAM, GDPR awareness, immutable audit trail
3. Budget — Respect $800/mo cap, auto-downgrade models, track per-call cost
4. Quality — No fabricated claims, no slop phrases, cite actual data
5. Resilience — Retry with backoff, graceful degradation, never crash daemon loop
6. Decisions — Log reasoning, escalate when uncertain
7. Learning — Record outcomes, flag patterns worth remembering

Total document under 500 tokens. Each principle 2-3 sentences max.

**Commit:** `feat(01-01): add universal engineering DNA document`

### Task 2: Per-daemon DNA profiles (DNA-02)

**Files:** `soul/dna/{daemon}.yaml` for titan, perseus, hermes, clawdbot, conway

Each YAML has: name, role, boundaries, permitted_tools, escalation_triggers, memory_domains.
See `.planning/phases/1/PLAN.md` Task 2 for the titan.yaml example — create similar for all 5.

**Commit:** `feat(01-01): add per-daemon DNA profiles for all 5 daemons`

### Task 3: DNA loader implementing DNAProvider (DNA-03)

**File:** `shared/agent_dna.py` (new)

Implement `AgentDNA` class:
- `load()` — Load universal DNA + daemon profile, verify signatures via skill_loader
- `get_dna(daemon_name)` — Return combined DNA string, capped at 500 tokens
- `get_token_budget()` — Return 500
- `get_boundaries()` — Return role boundaries list
- `check_action(action, tool)` — Check if tool is permitted

Must pass `isinstance(AgentDNA("titan"), DNAProvider)` check.
Run DNA content through injection_scanner before injecting.

**Commit:** `feat(01-01): add AgentDNA loader implementing DNAProvider Protocol`

### Task 4: Circuit breaker (DNA-04)

**File:** `shared/agent_dna.py` (extend)

Add `DNACircuitBreaker`:
- Tracks last 100 LLM call outcomes in deque
- Trips if error rate > baseline + 10%
- When tripped: DNA injection silently skipped
- Auto-reset after 50 consecutive successes
- Log breaker state to observability

**Commit:** `feat(01-01): add DNACircuitBreaker with auto-trip and reset`
