## CRITICAL: Graceful Fallback

TRIBE v2, torch, and nibabel are NOT installed. All code MUST:
- Use try/except ImportError for torch, tribev2, nibabel
- Provide a FallbackScorer that returns synthetic scores based on text heuristics
  (word count, question marks, personal pronouns, emotional words)
- TribeService has _TRIBE_AVAILABLE flag — when False, uses Haiku-based proxy scorer
- All tests use mocks — never require actual model loading
