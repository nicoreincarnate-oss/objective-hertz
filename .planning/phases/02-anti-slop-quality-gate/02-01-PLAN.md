# Plan 02-01: Anti-Slop Scorer + Rewrite Loop + Secrets + DB

## Objective

Build the standalone anti-slop quality engine — can be tested independently before pipeline integration.

Read `.planning/phases/2/PLAN.md` Tasks 1, 3, 4, 6, 7 for full implementation details.

## Tasks

### Task 1: 5-dimension quality scorer (SLOP-01)

**File:** `shared/anti_slop.py` (new)

Create `AntiSlopScorer` implementing `SlopScorer` Protocol:
- 5 dimensions: clarity, specificity, authenticity, value_density, slop_score
- Slop score: regex-based pattern count, no LLM needed. Load 60+ patterns.
- Other 4 dims: Haiku evaluation with structured rubric, returns JSON scores
- `score(content, context) -> dict[str, float]` (all 0.0-1.0)
- `get_threshold(context) -> float`
- Must pass `isinstance(AntiSlopScorer(), SlopScorer)` check
- Check `intel/anti-slop/` for reference patterns if directory exists

**Commit:** `feat(02-01): add 5-dimension AntiSlopScorer implementing SlopScorer Protocol`

### Task 2: Best-of-N rewrite loop (SLOP-03)

**File:** `shared/anti_slop.py` (extend)

Add `rewrite_loop(content, initial_scores, context, max_iterations=3)`:
- Track ALL versions with scores (including original)
- Generate rewrites using Haiku with feedback on what to fix
- Return **highest-scoring** version (not necessarily latest)
- Use `_composite_score()` helper to compare across dimensions
- Max 3 iterations enforced

**Commit:** `feat(02-01): add best-of-N rewrite loop returning highest scorer`

### Task 3: Good-enough thresholds (SLOP-04 + SLOP-08)

**File:** `shared/anti_slop.py` (extend)

Add configurable thresholds per content type:
- email: min_composite=0.7, max_slop=0.2 (strict)
- site_copy: min_composite=0.75, max_slop=0.15 (strict)
- alert: min_composite=0.5, max_slop=0.4 (relaxed)
- internal: min_composite=0.3, max_slop=0.6 (very relaxed)

`_is_good_enough(scores, context)` checks composite + slop thresholds.

**Commit:** `feat(02-01): add per-context good-enough thresholds`

### Task 4: Secret detection (SLOP-06)

**File:** `shared/anti_slop.py` (extend)

Add `detect_secrets(content) -> list[dict]`:
- 25+ regex patterns: API keys (sk-*, ghp_*, xoxb-*), AWS creds, passwords, CC numbers, SSNs, PII combos, private keys, JWT tokens, etc.
- If secrets found: return findings list with pattern description + count
- Integration: call before any outbound send — if findings, BLOCK content

**Commit:** `feat(02-01): add secret detection with 25+ regex patterns`

### Task 5: quality_scores table + DB functions (SLOP-07)

**Files:** `scripts/migrations/018-quality-scores.sql`, `shared/anti_slop.py` (extend)

Migration 018: CREATE TABLE quality_scores with all 5 dimension columns + composite + rewrite_count + indices.

Functions:
- `record_quality_score(reference_id, content_type, scores, rewrite_count)` — async INSERT
- `get_quality_trend(content_type, days=30)` — avg scores per day for trends

**Commit:** `feat(02-01): add migration 018 + quality_scores DB functions`
