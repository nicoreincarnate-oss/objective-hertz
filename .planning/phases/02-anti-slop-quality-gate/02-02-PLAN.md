# Plan 02-02: Pipeline Integration + Tests

## Objective

Wire the anti-slop engine into Titan email and ClawdBot site pipelines. Full test suite.

Read `.planning/phases/2/PLAN.md` Tasks 2, 5, 8 for full implementation details.

## Tasks

### Task 1: Email pipeline quality gate (SLOP-02)

**File:** `titan/pipeline/email_compose.py`

After LLM generates email body:
- Check `ENABLE_ANTI_SLOP` feature flag
- Score with `AntiSlopScorer(context="email")`
- Store scores via `record_quality_score()`
- If slop_score > threshold → trigger `rewrite_loop()`
- Run `detect_secrets()` — BLOCK if secrets found
- Flag off = zero change to existing behavior

**Commit:** `feat(02-02): wire anti-slop quality gate into email pipeline`

### Task 2: ClawdBot site copy gate (SLOP-05)

**File:** `clawdbot/site_builder.py`

Before Netlify deploy:
- Score all generated site copy sections with `context="site_copy"`
- Rewrite any section that fails threshold
- Run secret detection on all sections
- Log quality scores per section

**Commit:** `feat(02-02): wire anti-slop quality gate into site builder`

### Task 3: Full test suite

**Files:** `tests/shared/test_anti_slop.py` (new), `tests/titan/test_email_quality_gate.py` (new)

Also create `tests/titan/__init__.py` if it doesn't exist.

Tests:
- 5-dimension scoring with known slop (scores low) and clean content (scores high)
- Slop pattern detection: 20-sample corpus with known slop phrases → 80%+ detection
- Best-of-N returns highest scorer, not latest
- Good-enough threshold skips unnecessary rewrites
- Secret detection catches API keys, passwords, tokens, CC numbers
- Secret detection blocks content (returns error, doesn't pass through)
- quality_scores record + trend query (mock DB)
- `isinstance(AntiSlopScorer(), SlopScorer)` Protocol check
- Email pipeline: flag on → scores + gates, flag off → passthrough
- Email pipeline: detected secret → blocked
- Cost estimation: verify scoring uses Haiku model parameter

Run: `PYTHONPATH=. pytest tests/shared/test_anti_slop.py tests/titan/test_email_quality_gate.py -v`

**Commit:** `test(02-02): add anti-slop test suite — scoring, rewrites, secrets, pipeline`
