# Plan 05-01: RLM Composer + Context + Budget

## Objective

Build the recursive context retrieval engine for email composition.

Read `.planning/phases/5/PLAN.md` Tasks 1-5 for full details.

## Tasks

### Task 1: RLMComposer recursive loop (RLM-01)

**File:** `titan/pipeline/rlm_composer.py` (new)

Create `RLMComposer` class:
- `compose(lead, research, template)` — draft→evaluate→refine loop, max 3 iterations
- `_generate_draft(lead, research, context, previous_feedback, iteration)` — build prompt with specific business details
- Returns highest-scoring version (not latest)
- Uses `_composite_score()` from shared.anti_slop for comparison
- Context expansion targets weak scoring dimensions

**Commit:** `feat(05-01): add RLMComposer with recursive draft-evaluate-refine loop`

### Task 2: Mem0 write path (RLM-02)

**File:** `titan/pipeline/rlm_composer.py` (extend)

Add `store_research_context(lead_id, research)`:
- Store research sections in Mem0 per lead
- Return mem0_context_id linking to leads table
- Handle Mem0 unavailable gracefully (log warning, continue without)

**Commit:** `feat(05-01): add Mem0 write path for research context storage`

### Task 3: Qdrant read path (RLM-03)

**File:** `titan/pipeline/rlm_composer.py` (extend)

Add `_retrieve_context(lead, research)` and `_expand_context(lead, research, weak_dimension)`:
- Query Qdrant with lead company/industry/pain points
- Return top-10 relevant context items
- Expand context targets weak dimensions (e.g., specificity < 0.6 → pull competitor data)
- Handle Qdrant unavailable gracefully

**Commit:** `feat(05-01): add Qdrant read path for vector context retrieval`

### Task 4: Spend caps (RLM-04)

**File:** `titan/pipeline/rlm_composer.py` (extend)

Add `_check_budget()`:
- Per-email: $0.08 max, tracked during composition
- Monthly: $100/month global RLM spend (query llm_metrics)
- Budget exceeded → return best draft so far (graceful fallback)
- Integrate with observability metrics

**Commit:** `feat(05-01): add per-email and monthly RLM spend caps`

### Task 5: Migration 021 (RLM-02 support)

```sql
ALTER TABLE leads ADD COLUMN IF NOT EXISTS mem0_context_id TEXT;
```

**Commit:** `feat(05-01): add migration 021 — mem0_context_id on leads table`
