## Integration Findings

### CRITICAL: Logger Not Defined in engine.py

`openjarvis/workflow/engine.py` lines 198 and 241 reference `logger` but the module has no `import logging` or logger setup. When `ENABLE_MIDDLEWARE=true` and the middleware import fails or chain raises, `NameError` will crash instead of gracefully falling back.

**Affects:** MW-01, MW-08

### HIGH: memory_cleanup Handler Missing

Perseus scheduler has `Schedule("memory_cleanup", 86400, ...)` but no daemon's `TASK_HANDLERS` maps `"memory_cleanup"` to `DaemonMemoryStore.cleanup_expired()`. The task is enqueued daily and silently dropped. `daemon_memory` table grows unbounded.

**Affects:** MEM-03
